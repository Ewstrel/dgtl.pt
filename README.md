# dgtl.pt

Personal site for Gene Strelnikov.

## Overview

This repository contains the source for `dgtl.pt`, a lightweight personal website focused on professional profile, positioning, and contact routing.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deployment

The site is deployed through GitHub Pages from the `main` branch via GitHub Actions.
